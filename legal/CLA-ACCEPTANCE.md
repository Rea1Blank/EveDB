## Submission

Ask the project owner through your pull request for a private submission channel
if the completed form contains personal information. Do not post private
addresses or confidential employer records in an issue or pull request.

Submit a signed copy to the owner. A signed Git commit containing the completed
form may be used for an electronic acceptance if the owner verifies the
signature, signer identity, and authority. The owner may request an additional
written signature or authorization where needed. Use a form of signature valid
under the law that applies to you.

The owner retains the acceptance, its digest, the contributor's numeric GitHub
ID, authorized commit emails, date, and evidence of any employer authorization.
Only the public registry entry described in CONTRIBUTING.md is committed here.
