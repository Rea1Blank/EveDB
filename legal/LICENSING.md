## Changes, distribution, and network use

The source-sharing obligations depend on how the software is used and shared:

- Running an unmodified copy, including as a network service, does not by itself
  create an obligation to disclose an independent application's source code.
- If you modify EveDB and let users interact with that version over a network,
  section 13 requires a prominent offer of the Corresponding Source of that
  version to those users, at no charge.
- Distributing copies carries the license's notice and licensing obligations.
  Distributing object code also requires a compliant way to provide the
  Corresponding Source, even when the distributed code is unmodified.
- Private modifications without distribution or interaction with other users
  over a network do not require general public publication solely because a
  modification was made.

Corresponding Source means the source covered by the license's definition,
not merely a patch containing changed lines. An independent client is not
automatically covered merely because it communicates with EveDB over a network.
Combining or linking code requires a separate assessment under the license.

This summary does not add exceptions to or replace the AGPL terms.
