The unmodified PolyForm Noncommercial License 1.0.0 in [LICENSE](../LICENSE)
governs the public code. Its permitted purposes include noncommercial uses,
specified personal uses, and uses by the organizations described in that
license. Read those terms when deciding whether a use is permitted.

This is a source-available license, not an OSI-approved open-source license.
The license does not require publishing modifications.

## Commercial licensing and network use

Uses outside the public license's permitted purposes require a separate written
commercial agreement with the individual operating
[Rea1Blank](https://github.com/Rea1Blank), GitHub account ID 72102806.

Commercial hosting, managed database services, and operating the software as
part of a commercial application are not automatically permitted because the
software is accessed over a network rather than distributed. The public
license's permitted-purpose requirements also apply to operating the software.
An independent client is not automatically covered by EveDB's license merely
because it sends requests to a server.

Publishing the database's or an application's source code does not replace the
need for permission for an otherwise unlicensed commercial use. No commercial
license or pricing is offered by this repository itself.

For a commercial licensing request, open a GitHub issue with a non-confidential
description and ask the owner for a private contact channel if needed.

## Contributions and future ownership

The [CLA](CLA.md) grants the project owner rights to distribute and commercially
relicense accepted contributions. It preserves each contributor's ownership.
A DCO sign-off or a Git signature alone does not grant these additional rights.

The owner is currently an individual identified by the GitHub account above,
not a company. Forming a company or moving the GitHub repository does not by
itself transfer existing rights. The CLA permits a documented transfer to a
successor that takes over the project; record such a transfer and update these
documents when it happens.

The CLA is project-specific. Its legal sufficiency, including identification
by an online account and electronic execution, depends on applicable law.
Obtain legal review before relying on it for commercial licensing or a transfer
to a company.
